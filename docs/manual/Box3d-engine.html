[name] version 0.1.0

The new Box3d from Erin Catto's is 3D rigid body physics engine
JS compiled with Emscripten is ultra light and very powerfull !
( no real d6 joint, compound body can't move and dynamic convex complexity is limited for optimization purposes. )
Integration in progress...

Code Example

import { phy } from './build/Phy.module.js'; phy.init({ type:'BOX3D', worker:false, callback:startDemo, scene:scene, path:'./build/' })

Resources need

in /build folder
Box3d.module.js __ module version
or Box3d.min.js __ for worker version

in /compact folder
Box3d.bin or Box3d.module.bin __ compact version
